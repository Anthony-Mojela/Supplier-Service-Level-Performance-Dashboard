# 📊 Supplier Service Level Performance Dashboard  
**Retail Analytics | Operations & Supply Chain | Excel BI**

## 📌 Project Overview  
This project focuses on building an interactive Excel dashboard used in a retail environment to **monitor and communicate supplier service level performance**.  

The dashboard is designed to support retailer–supplier engagements by highlighting service gaps, performance trends, and improvement opportunities.

---

## 🎯 Business Problem  
Retailers rely heavily on suppliers for consistent product availability. Poor supplier performance leads to:
- Stock-outs and lost sales  
- Operational inefficiencies  
- Increased costs  

The goal of this project was to transform raw operational data into a **decision-support tool** that allows both internal teams and suppliers to track service performance and take corrective actions.

---

## 📊 Key Features  
- Supplier service level KPIs  
- Performance trends over time  
- Supplier and category comparisons  
- Identification of underperforming suppliers  
- Exception-focused views for faster decision-making  
- Automated refresh-ready structure

---

## 🧠 Analytics & Business Value  
- Converts operational data into measurable KPIs  
- Enables data-driven supplier review sessions  
- Supports supply chain improvement strategies  
- Encourages accountability and performance transparency

---

## 🛠 Tools & Skills  
- Microsoft Excel  
- Power Query (ETL & data cleaning)  
- PivotTables & data modeling  
- Advanced Excel formulas  
- KPI development  
- Dashboard design & storytelling

---

## 🔐 Data Privacy  
All company names, supplier names, and figures have been **masked and anonymized**.  
This project demonstrates analytical structure, logic, and design — not real company data.
